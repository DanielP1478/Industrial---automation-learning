# Industrial---automation-learning
Industrial Automation Telemetry Simulation
A Python-based industrial monitoring system that models real-world Programmable Logic Controller (PLC) architectures. This engine evaluates manufacturing data streams against mechanical and electrical safety thresholds, dynamically calculating the downstream corporate financial impact of system faults.

🚀 Core Features
Sensor Telemetry Engine: Simulates active industrial sensor loops tracking real-time machine IDs, operational voltage inputs, and thermal threshold dynamics.
Algorithmic Financial Risk Modeling: Quantifies assembly line downtime penalties by directly translating technical operational faults into high-impact corporate monetary deficits (e.g., tracking a £7,500.00 loss over a 15-minute overheat interval).
Persistent Anomaly Logging: Implements discrete, automated fault-handling to record critical anomalies sequentially into a dedicated machine_errors.log file without overriding previous state records.

💻 Tech Stack
Language: Python 3
Core Libraries: time (loop delay automation), random (telemetry generation), datetime (log micro-timestamper)
Environment: Headless terminal executions & Git Version Control

🛠️ Operational Setup
To run the factory monitoring sprint locally:
python factory_monitor.py
